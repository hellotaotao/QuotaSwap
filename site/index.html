Switch Claude accounts without signing out.

QuotaSwap keeps a login for each of your Claude accounts and swaps the desktop app between them in one click. Your Code sessions come along, and every account's usage sits in the menu bar.

brew install --cask hellotaotao/tap/quotaswap
Download for Mac

Free and open source. macOS 13 or later, Apple silicon and Intel, notarized by Apple.

Try it: switch to the other account.

What QuotaSwap does

Switch in one click

QuotaSwap saves each account's login on your Mac. Switching quits Claude, swaps the login and reopens it already signed in. No browser, no password, no waiting for an email code.

Keep your Code sessions

The Claude desktop app gives each account its own list of Code sessions. QuotaSwap merges the lists every time you switch, so a session you started on one account is right there on the other, with its whole history.

See every account's usage

Each account shows how much of its 5-hour and weekly limit is used and when each resets, refreshed every five minutes. The menu bar shows the account you're signed in to, so you know when it's time to switch.

Know if you'll make it to the reset

A percentage alone doesn't tell you much. 60% used is fine near the end of the week and a problem on day two. Each bar carries a tick that marks how much of the window has already passed, and its color compares the two.

Getting started

  1. Save the account you're signed in to

    Open QuotaSwap from the menu bar and click Save this account.

  2. Add your other account

    Click Add account. Claude restarts at its sign-in screen, and the account you just saved stays saved.

  3. Sign in and save it

    Sign in to the other account in Claude as usual, then click Save this account again. This is the last time you sign in.

  4. Switch whenever you like

    Click Use account next to any account. Claude restarts signed in to it, with all your Code sessions.

The first time QuotaSwap reads usage, macOS asks whether it may use the "Claude Safe Storage" keychain item. QuotaSwap needs it to read Claude's session cookie on your Mac. Choose Always Allow and you won't be asked again.

What it touches

Everything stays on your Mac. The only network requests QuotaSwap makes are usage requests to claude.ai, sent with each account's saved session. There is no QuotaSwap account, no server and no telemetry.

Claude doesn't document any of this, so QuotaSwap checks it before every change. If a Claude update moves things around, switching turns off and the menu says which check failed. Nothing is written until an updated QuotaSwap knows the new layout.

Questions

Will switching interrupt what Claude is doing?

Yes. Switching quits and reopens Claude, so chats and Code sessions that are running stop. QuotaSwap asks before every switch.

Can I use Claude's own Log out?

Use Add account in QuotaSwap instead. Logging out in Claude may end that login on Anthropic's side, and you'd have to sign in and save the account again.

Does it switch the Claude Code command-line tool too?

No. QuotaSwap switches the Claude desktop app, including its Code tab. The claude command in your terminal keeps its own login.

Is it useful with only one account?

Yes. The menu bar usage and pace bars work the same for a single account.

How do I update or uninstall it?

With Homebrew, run brew upgrade --cask quotaswap, or brew uninstall --zap --cask quotaswap to remove it with its saved logins. Claude stays signed in to whichever account you used last.

Is this made by Anthropic?

No. QuotaSwap is an independent open-source project and isn't affiliated with or endorsed by Anthropic. Use it within Anthropic's terms for your plans.
